# Nexa — Landing Page Project

A responsive fictional-company landing page built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features
- Responsive header and navigation
- Mobile hamburger menu
- Hero section with CTA
- Three service/feature cards
- Three customer testimonials
- Contact CTA and footer with social links
- Smooth scrolling
- Scroll-reveal animations
- Accessible labels and reduced-motion support
- No framework or external dependencies

## Project structure
- index.html — page structure and content
- styles.css — responsive styling and animations
- script.js — navigation and scroll interactions

## Run locally
Open index.html in a browser, or serve the folder with any static HTTP server.

## Deployment
The project is suitable for GitHub Pages, Netlify, or Vercel because it is a static site.

## Note
Nexa is a fictional company created for a landing-page development assignment.
